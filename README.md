# Production-Ready Inventory & Order Management System

A highly polished, responsive, and containerized Inventory & Order Management System. Built using:
- **Backend**: Python + FastAPI + SQLAlchemy + PostgreSQL
- **Frontend**: React + Vite + Vanilla CSS (Rich Custom Design System)
- **Deployment**: Production Dockerfiles & Docker Compose

---

## Technical Features

1. **Dashboard Analytics**: Real-time summary metrics for Products, Customers, Orders, and Low Stock Alerts.
2. **Product Management**: SKU uniqueness validation, non-negative quantity check, and full CRUD.
3. **Customer Management**: Email uniqueness check, full CRUD operations.
4. **Order Management**: Automatic calculation of order totals on the backend, inventory availability checks, and automatic stock deduction upon order creation.
5. **Docker Orchestration**: Complete compose setup with persistent database volumes, secure environment configurations, and lightweight production-ready images.
